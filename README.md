# AutoMacro

윈도우에서 마우스·키보드 동작을 녹화하고 시나리오로 엮어 반복 실행하는 매크로 프로그램입니다.
**무료로 쓸 수 있습니다.**

소개와 최신 버전 받기: **https://dev.chilgong88.com**

## 이 저장소에 대해

**이 저장소는 배포 전용입니다.** 설치 파일을 내려받는 곳이며, **소스 코드는 공개하지 않습니다.**
받으실 파일은 [Releases](../../releases) 에 있습니다.

## 설치할 때

- 코드 서명을 하지 않아 설치할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다.
  **추가 정보 → 실행** 을 누르면 계속 설치됩니다.
- 키보드·마우스 입력을 기록하고 재생하는 프로그램이라 **백신이 오탐하는 경우가 있습니다.**
  설치가 막히면 백신의 검역 목록을 확인해 주세요.
